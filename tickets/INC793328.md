## 4. Root Cause & KB Notes

**Root Cause:** A browser-based full-screen scareware page (web-based tech support scam) hijacked the browser window to display a fake lock screen with audio alarms and a countdown timer, pressuring the user into calling a fraudulent support line. No malware was actually installed on the endpoint; force-closing the browser process and verifying with a full antivirus scan confirmed the device was clean.

**KB Article:** KB-1077

**Quick Resolution Checklist:**
1. Advise the user immediately to **NOT** call the displayed phone number or provide any credentials.
2. Establish a **Remote Desktop** connection to the affected endpoint.
3. Force-close the active web browser process displaying the full-screen lock page (e.g., via Task Manager or Alt + F4).
4. Open **Settings → Security → Virus & threat protection**.
5. Select **Full scan** and initiate the scan to ensure no persistent secondary payloads were downloaded.
6. Clear browser cookies and cache to prevent auto-restoration of the malicious page upon re-opening the browser.
7. Verify clean scan results (**"No threats detected"**) and confirm functionality with the user before closing the ticket.
