## 4. Root Cause & KB Notes

**Root Cause:** Active Directory account password expiration (**Password expired: Yes**) blocked authentication across mobile Exchange sync, webmail, and laptop logins. After identity verification, an administrative password reset issued a temporary credential, and the user set a new password to restore access.

**KB Article:** KB-1083

**Quick Resolution Checklist:**
1. Open **Directory** and search for the affected user's UPN/Email.
2. Select **Authentication** under the Manage pane.
3. Check the **Password expired** attribute. If set to Yes, proceed with account credential reset procedures.
4. Perform mandatory **Identity Verification** by issuing a verification code to the registered out-of-band device/phone.
5. Click **Reset Password** to generate a temporary secure passcode.
6. Provide the temporary passcode to the user via an authenticated secondary communication channel.
7. Confirm that the user updates their password and that Exchange ActiveSync automatically re-authenticates on mobile hardware.
