## 4. Root Cause & KB Notes

**Root Cause:** User fell victim to a phishing email link resolving to **secure-account-verify.live**, leading to unauthorized app installation (PC Speed Manager). Account credentials were reset, the rogue application uninstalled, and a full antivirus scan remediated one threat, restoring the system to a clean state.

**KB Article:** KB-1086

**Quick Resolution Checklist:**
1. Locate the affected user in **Directory / Active Directory** and issue a **Password Reset** to invalidate potentially stolen credentials.
2. Provide the temporary password securely via **Team Chat** and instruct the user to change it upon login.
3. Verify **MFA** status; flag non-enrolled users for MFA onboarding.
4. Connect remotely to the workstation and open **Control Panel → Programs and Features**.
5. Identify and uninstall any unauthorized third-party application (e.g., PC Speed Manager).
6. Open **Workstation OS Security** and run a **Full Scan**, confirming all threats are detected and removed before closing the ticket.
