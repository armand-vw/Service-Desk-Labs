## 1. Issue Description

User's laptop failed to resume from a suspended sleep state. The screen remained entirely black while the power LED blinked slowly, and single presses on the power button produced no response.

![Problem](tickets/INC220144/screenshot-1-ticket.png)

---

## 2. Investigation & Triage

- A slowly blinking power light typically signifies the system is stuck in an **ACPI power state** (S3 Sleep or Modern Standby).
- The ACPI state machine froze due to low-level firmware or memory state corruption — normal input interrupts (keyboard, trackpad, power button) failed to trigger the wake routine.
- A full power drain is required to reset the Embedded Controller (EC) and flush hardware registers.

---

## 3. Resolution Steps

1. Contacted the user via **Team Chat** for real-time guided troubleshooting.
2. Instructed the user to perform a **hard power reset**: press and hold the physical power button continuously for **30 seconds** (until fans and status LEDs ceased activity).
3. Advised the user to release the button once fully powered off, wait a moment, then press the power button once normally to initiate a fresh POST sequence.
4. User confirmed the device powered on and reached the desktop: *"I did the hard reset and it's all working now! Thanks so much!"*

---

## 4. Root Cause & KB Notes

**Root Cause:** Frozen ACPI state machine (firmware/memory state corruption) left the laptop stuck in a sleep/standby state. A full power drain was required to reset the Embedded Controller.

**KB Article:** KB-1068

**Quick Resolution Checklist:**
1. Connect with the end-user via chat or phone.
2. Direct the user to press and hold the **Power Button** continuously for **30 seconds**.
3. Confirm the blinking power light turns off completely and all system activity stops.
4. Instruct the user to wait 5 seconds, then press the power button normally (1–2 seconds).
5. Verify the device completes POST, loads the OS, and returns to normal operation.
