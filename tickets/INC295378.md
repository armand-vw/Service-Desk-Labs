## 4. Root Cause & KB Notes

**Root Cause:** The workstation entered BitLocker recovery mode, requiring the 48-digit recovery key to unseal the encrypted system drive. Identity was verified via MFA before the key was retrieved from Active Directory and applied to unlock the device.

**KB Article:** KB-1075

**Quick Resolution Checklist:**
1. Open **Tools → Directory** and search for the affected user's account.
2. Select **AUTHENTICATION** and click **Send Verification Code** to send an MFA prompt to the user's registered phone.
3. Obtain the code back from the user via secure communication (Phone/Team Chat) to confirm identity.
4. Once verified, navigate to the **DEVICES** tab under the user's Directory profile.
5. Locate the matching target device ID and copy/read the 48-digit Drive Encryption Recovery Key.
6. Enter the recovery key into the endpoint prompt to unseal the drive and boot into OS.
