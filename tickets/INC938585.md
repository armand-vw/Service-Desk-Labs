## 1. Issue Description

User reported relentless desktop pop-up advertisements ("Congratulations!", fake "Security Alerts") interrupting workflow. Pop-ups persisted even when the web browser was not actively in use or when manually closed.

![Problem](tickets/INC938585/image-1-intake.png)

---

## 2. Investigation & Triage

- Established remote support session to workstation **SD1020**.
- Identified the delivery mechanism as malicious **Web Push Notification** permissions configured within the browser settings — not a traditional malware infection.
- Modern browsers process background notification push hooks independently of active tabs, allowing permitted sites to continuously throw system-level pop-ups.

![Intrusion](tickets/INC938585/image-2-popup-intrusion.png)

---

## 3. Resolution Steps

1. Navigated to **Tools → Remote Support** and initiated a remote desktop connection to SD1020.
2. Opened Web Browser → **Settings → Notifications**.
3. Removed all unrecognized/untrusted site entries from the **Allowed to send notifications** list, ensuring the list displayed "No sites can send notifications."

   ![Notification Revocation](tickets/INC938585/image-3-notification-revocation.png)

4. Ran a **Full Scan** via **Settings → Security → Virus & threat protection**.
5. Scan completed cleanly — zero threats detected, confirming no persistent malware.
6. User confirmed via Team Chat that pop-ups had ceased and system behavior returned to normal.

---

## 4. Root Cause & KB Notes

**Root Cause:** User inadvertently granted notification permissions to an unauthorized web domain. Browser push notification hooks run independently of active tabs, enabling continuous system-level pop-ups.

**KB Article:** KB-1061

**Quick Resolution Checklist:**
1. Connect to the host via **Tools → Remote Support**.
2. Open browser **Settings → Privacy and Security → Notifications**.
3. Under **Allowed to send notifications**, review and remove/block all unrecognized external domains.
4. Run a **Full Scan** via **Settings → Security** to clear any staging scripts or adware leftovers.
5. Confirm with end-user that background pop-ups have completely ceased.
