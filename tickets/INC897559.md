## 1. Issue Description

User reported that two external monitors were no longer detected through his docking station. The primary DisplayPort cable had been flaky for weeks before total connection failure. The integrated laptop panel remained functional.

- Integrated laptop panel functioned normally, isolating the fault to the **DisplayPort cable/docking connection**.
- **Business impact:** interrupted dual-monitor engineering workflow, leading to reduced productivity.

## 4. Root Cause & KB Notes

**Root Cause:** Faulty DisplayPort cable caused intermittent and eventual total loss of external display detection through the docking station. Replacement cabling was dispatched via Ship Manager to restore dual-display functionality.

**KB Article:** KB-1076

**Quick Resolution Checklist:**
1. Open Team Chat and contact the affected user to confirm exact display interface requirements (HDMI vs. DisplayPort) and current delivery address.
2. Open **Tools → Ship Manager**.
3. Select IT Department as the sender and choose the active ticket reference (INCXXXXXX).
4. Select the matching cable specification under Equipment to ship.
5. Set Shipping speed to **Rush Priority (Instant)** and click **SHIP**.
6. Confirm physical delivery and verify display output restoration with the user in Team Chat prior to closing the ticket.
