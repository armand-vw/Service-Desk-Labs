## 1. Issue Description

Support agent Patrick O'Brien reported severe screen flickering and visual artifacts — colored blocks and horizontal/vertical lines — affecting both his primary laptop display and external monitor. The issue began immediately following a Workstation OS update.

![Screenshot 1 Ticket](tickets/INC619386/screenshot-1-ticket.png)

---

## 2. Investigation & Triage

- Claimed ticket **INC619386** and established a remote session to workstation **SD1007**.
- Launched the **System Update** tool and scanned for pending updates.
- Identified outdated system components:
  - **Integrated Graphics Driver:** 31.0.101.4887 → 31.0.101.5186 (380 MB)
  - **BIOS Update:** v1.58 → v1.62
  - **System Firmware Update:** v2.1 → v2.4
- **Business impact:** high priority — workstation display was virtually unreadable, threatening delivery of urgent design projects due the following day.

![Screenshot 2 Graphics driver update](tickets/INC619386/screenshot-2-graphics-driver-update.jpg)

---

## 3. Resolution Steps

1. Established a remote session to **SD1007** and informed the user via **Team Chat** that troubleshooting was underway.
2. Opened the **System Update** tool and scanned pending updates.
3. Installed the updated **Integrated Graphics Driver (31.0.101.5186)** to resolve video pipeline rendering issues.
4. Allowed the display adapter to re-initialize; verified screen stability with zero line distortion.
5. Contacted Patrick via **Team Chat** to confirm; user verified full functionality: *"Oh, great! I just checked and everything's working perfectly now. Thanks a ton for the quick fix!"*

## 4. Root Cause & KB Notes

**Root Cause:** Display driver instability/incompatibility between the updated Workstation OS build and the legacy Intel Integrated Graphics driver (v31.0.101.4887). Updating the driver to v31.0.101.5186 resolved the rendering artifacts and eliminated display flickering.

**KB Article:** KB-1084

**Quick Resolution Checklist:**
1. Establish a remote desktop session to the user's workstation.
2. Open the OEM vendor update suite or **Device Manager / System Update**.
3. Check **Display Adapters** for outdated graphics drivers post-OS deployment.
4. Download and apply the latest certified Integrated Graphics Driver release.
5. If the prompt requires a restart, initiate reboot and re-verify display rendering.
6. Validate resolution with the end user before closing the ticket.
