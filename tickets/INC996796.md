## 4. Root Cause & KB Notes

**Root Cause:** Potential credential compromise or session hijacking resulting in an unauthorized login from an unknown location. Following identity verification, the account was hardened via password reset, MFA reset, and a clean endpoint security scan, and the incident was escalated to the Security Operations Center for forensic analysis.

**KB Article:** KB-1081

**Quick Resolution Checklist:**
1. Open **Directory** and search for the compromised account.
2. Go to the **Authentication** tab and complete out-of-band identity verification via registered contact info.
3. Click **RESET PASSWORD** to force credential change and revoke active session tokens.
4. Click **RESET MFA** to force re-enrollment and purge compromised MFA factors.
5. Establish a **Remote Support** session to the user workstation, navigate to **Settings → Security**, and run a **Full Scan**.
6. Once local remediation steps complete, escalate the incident directly to the **Security Operations Center (SOC)** for forensic analysis.
