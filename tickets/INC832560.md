## 4. Root Cause & KB Notes

**Root Cause:** Forgotten domain password following scheduled leave. Identity verification and MFA status were confirmed before a temporary password was generated and securely delivered, allowing the user to authenticate and set a new permanent password.

**KB Article:** KB-1087

**Quick Resolution Checklist:**
1. Open **Directory Services** and locate the user record using UPN or account name.
2. Under **Manage → Authentication**, confirm identity verification status and MFA enrollment.
3. Select **Reset Password** to generate temporary access credentials.
4. Transmit temporary credentials securely through an authenticated internal communication channel (e.g., direct chat).
5. Ensure the user completes a mandatory password change upon initial authentication.
6. Record resolution details and close the ticket upon user confirmation.
