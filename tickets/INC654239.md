## 1. Issue Description

User reported browser search hijacking and performance degradation. New tabs and searches defaulted to an unauthorized portal (**SearchWave** at `search-wave.co`), returning ad-heavy search results. The browser also experienced severe sluggishness and latency.

![Problem](tickets/INC654239/screenshot-1-ticket.png)

---

## 2. Investigation & Triage

- Established a remote session to workstation **SD1022**.
- Navigated to **browser://settings → Extensions** and cross-referenced installed add-ons against internal IT policy (**Documentation Station → Approved Browser Extensions**).
- Root cause: an unapproved extension (**Free PDF Converter Pro**) was injecting search redirects to SearchWave.
- Per IT policy, only Corporate Password Manager, PDF Viewer, and Dark Reader are vetted for corporate deployment.

![Hijack](tickets/INC654239/screenshot-2-problem.png)

![Extensions](tickets/INC654239/screenshot-3-checking-extensions.png)

![Approved List](tickets/INC654239/screenshot-4-approved-extensions-doc.png)

---

## 3. Resolution Steps

1. Identified **Free PDF Converter Pro** as non-compliant against the approved extensions baseline.
2. Clicked **REMOVE** to uninstall the unauthorized add-on.

   ![Removed](tickets/INC654239/screenshot-5-removed-extension.png)

3. User confirmed search redirects ceased, but browser sluggishness persisted.
4. Navigated to **browser://settings → Reset settings** and selected **RESTORE SETTINGS TO THEIR ORIGINAL DEFAULTS** to clear modified search parameters, startup pages, and cached state while retaining bookmarks and passwords.
5. User confirmed normal operation — "everything's running smoothly now."

---

## 4. Root Cause & KB Notes

**Root Cause:** Unapproved browser extension (Free PDF Converter Pro) injected search hijacking (SearchWave) and caused performance degradation. Lingering cached state and modified search parameters persisted after extension removal, requiring a settings reset.

**KB Article:** KB-1065

**Quick Resolution Checklist:**
1. Open the affected browser and navigate to **Settings → Extensions**.
2. Cross-reference installed add-ons against IT Policy (**Documentation Station → Approved Browser Extensions**).
3. Remove any unauthorized or unvetted extensions.
4. If sluggishness or altered search defaults persist, navigate to **Settings → Reset settings**.
5. Click **RESTORE SETTINGS TO THEIR ORIGINAL DEFAULTS** to clear corrupted startup pages, search overrides, and cached state.
6. Launch a new tab, confirm default search engine behavior, and verify resolution with the end-user.
