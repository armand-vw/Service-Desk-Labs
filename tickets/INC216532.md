## 4. Root Cause & KB Notes

**Root Cause:** Corrupted or missing updated graphics drivers caused a software-rendering fallback, resulting in degraded display performance. Updating the Integrated Graphics Driver to v31.0.101.5186 via the System Update utility and applying a system restart restored normal visual performance.

**KB Article:** KB-1079

**Quick Resolution Checklist:**
1. Connect to the affected user PC via **Remote Desktop**.
2. Open the **System Update** application.
3. Click **Check for updates** to fetch missing or outdated display drivers.
4. Select and install all pending updates, paying specific attention to Integrated Graphics Driver releases.
5. Click **RESTART NOW** to finish applying the updated graphics driver.
6. Confirm visual responsiveness and video playback stability with the user in **Team Chat** prior to ticket closure.
