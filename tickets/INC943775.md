## 1. Issue Description

User recently transferred to the Engineering department and could not access the team's shared folder. File Explorer returned a **"network path not found"** error. The shared network drive was not automatically mapped following the department transfer, despite AD group membership already being provisioned.

## 2. Investigation & Triage

- Active Directory group membership (Engineering) was already provisioned — the user had correct permissions at the server level.
- Automatic **Group Policy Object (GPO)** drive mapping scripts had not yet propagated to the user's profile post-transfer.
- The logical UNC share path needed to be manually mapped on the endpoint to bridge the gap while GPO sync caught up.

## 3. Resolution Steps

1. Connected to workstation **SD1026** via **Tools → Remote Support** and verified active Corporate VPN connectivity (`vpn.corp.local:443`).
2. Referenced **Tools → Documentation Station → File Server** to locate the correct SMB UNC path.

<img width="1918" height="875" alt="Screenshot 3 Looking at Documentation" src="https://github.com/user-attachments/assets/baa8e159-fa4f-4bd2-a2e4-393380137e64" />


3. Opened File Explorer → **Map Network Drive**, selected **Drive Letter D:**, and entered:

   ```
   \\FILESERV01\departments\Engineering
   ```

<img width="1918" height="878" alt="Screenshot 4 Mapping Drive" src="https://github.com/user-attachments/assets/14c5e919-8817-45ae-b1b5-ffde08ef8176" />


4. Completed connection — drive `D: ENGINEERING DEPARTMENT DRIVE` appeared under **This PC**.
5. User confirmed via Team Chat that the shared folder was visible, accessible, and fully operational.

---

## 4. Root Cause & KB Notes

**Root Cause:** GPO drive mapping scripts had not fully propagated to the user's profile after department transfer. AD permissions were correct; the UNC path simply needed manual mapping.

**KB Article:** KB-1062

**Quick Resolution Checklist:**
1. Verify active VPN or LAN connectivity to ensure file server (FILESERV01) reachability.
2. Open **File Explorer → This PC → Map Network Drive**.
3. Select available drive letter (e.g., D:) and input the target UNC:
   - `\\FILESERV01\departments\Engineering`
   - `\\FILESERV01\departments\Sales`
   - `\\FILESERV01\departments\Finance`
4. Check **Reconnect at sign-in** and click **Finish**.
5. Confirm directory contents load cleanly in File Explorer.
