## 4. Root Cause & KB Notes

**Root Cause:** Internal motherboard/power delivery hardware failure rendered the laptop non-responsive. The device was replaced via the Cloud Provisioning workflow and dispatched through Ship Manager to restore the remote agent to operational status.

**KB Article:** KB-1073

**Quick Resolution Checklist:**
1. Open **Tools → Computer Deployment** and consult PC Setup guidelines.
2. Select **Cloud Provisioning** for remote workers needing cloud identity registration.
3. Complete hardware setup steps (mains power + network connectivity) until domain credentials register.
4. Obtain the user's current destination address via Team Chat.
5. Open **Ship Manager**, input recipient information, attach ticket reference INCXXXXXX, select appropriate shipping priority, and click **SHIP**.
