## 1. Issue Description

User reported that corporate email failed to synchronize on his mobile device, displaying a **"Cannot connect to server"** error and stopping inbound message retrieval. Mail remained fully operational on his desktop laptop, confirming account credentials and mailbox server status were healthy.

![Screenshot 1 Ticket](tickets/INC605051/screenshot-1-ticket.png)

---

## 2. Investigation & Triage

- Email access functioned without issue on the user's laptop, ruling out **server-side account lockouts, password expirations, and Exchange/mail server outages**.
- The fault was isolated to a **corrupted local cache, expired ActiveSync session token, or broken configuration state** within the mobile mail application.

---

## 3. Resolution Steps

1. Initiated contact with Tom Wilson via **Team Chat**.
2. Confirmed email services operated normally on secondary endpoints (laptop).
3. Instructed the user to **uninstall** the mobile mail application from his smartphone to completely wipe stale application data, cached tokens, and broken sync configurations.
4. Guided the user to **reinstall** the application from the official app store and complete a fresh sign-in.
5. The user completed the reinstall and sign-in sequence, successfully establishing connection to the mail server.
6. User verified full email synchronization via Team Chat: *"Let me try... ok it's working now! Thank you so much!"*

![Screenshot 2 Solution](tickets/INC605051/screenshot-2-solution.png)

---

## 4. Root Cause & KB Notes

**Root Cause:** Corrupted local cache, expired ActiveSync session token, or broken configuration state within the mobile mail application. Server-side credentials and mailbox status were intact, confirmed by working access on the user's laptop.

**KB Article:** KB-1070

**Quick Resolution Checklist:**
1. Connect with the end-user via Team Chat or phone.
2. Confirm secondary access (e.g., laptop/webmail) is functioning properly to rule out account lockouts or server outages.
3. Instruct the user to completely uninstall the mobile mail application from their phone.
4. Direct the user to download and reinstall the application from the official device app store (iOS App Store / Google Play Store).
5. Have the user open the app and perform a fresh login with corporate credentials.
6. Confirm inbox sync completes and emails begin flowing normally.
