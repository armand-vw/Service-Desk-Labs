## 4. Root Cause & KB Notes

**Root Cause:** Accidental local file deletion compounded by clearing the local OS trash bin. Because the data resided in a synchronized Cloud Drive directory, the deleted folder remained recoverable via the cloud-based Version History / Recently Deleted Files repository and was restored in full.

**KB Article:** KB-1080

**Quick Resolution Checklist:**
1. Connect to the user's machine via **Remote Desktop**.
2. Open **File Explorer** and navigate to the root **Cloud Drive** folder.
3. Click **VERSION HISTORY** in the upper toolbar.
4. Select **Recently Deleted Files** to view cloud-backed deletions (available up to 30 days post-deletion).
5. Locate the deleted file or folder and click **RESTORE**.
6. Verify that the files reappear in the user's active directory and confirm integrity with the user in **Team Chat** before closing the ticket.
