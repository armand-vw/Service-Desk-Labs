## 1. Issue Description

User requested assistance configuring corporate email on a newly acquired mobile phone. The default mail application failed to establish a server connection during automated setup — native apps frequently lack pre-configured Autodiscover DNS record mappings for private domains.

![Problem](tickets/INC628205/image-1-intake.png)

---

## 2. Investigation & Triage

- Mobile email clients often fail auto-discovery protocols without explicit Exchange/ActiveSync endpoints.
- Manual entry of hostname, secure port bindings, and SSL/TLS encryption parameters is required.
- Referenced internal **Documentation Station** for corporate mail server parameters.

---

## 3. Resolution Steps

1. Opened **Tools → Documentation** and navigated to **EMA I L & MAIL SERVER → Mobile Email Setup**.

   ![Documentation](tickets/INC628205/image-2-mobile-email-setup.png)

2. Retrieved mandatory server parameters:

   | Parameter          | Value                                              |
   |--------------------|----------------------------------------------------|
   | **Server (Host)**  | `mail.servicedesk-simulator.com`                   |
   | **Port**           | `443`                                              |
   | **Encryption**     | SSL/TLS                                            |

3. Transmitted verified connection parameters to the user via **Team Chat**.
4. Guided user through applying settings on device (**Settings → Mail → Accounts**).
5. User confirmed successful verification, connection, and real-time mailbox sync.

---

## 4. Root Cause & KB Notes

**Root Cause:** Native mobile mail clients lack pre-configured Autodiscover DNS mappings for private domains, requiring manual ActiveSync/Exchange endpoint configuration.

**KB Article:** KB-1060

**Quick Resolution Checklist:**
1. Access internal KB at **Tools → Documentation → Email & Mail Server → Mobile Email Setup**.
2. Advise user to open device mail settings (**Settings → Mail → Accounts** on iOS, **Settings → Accounts** on Android).
3. Populate incoming server settings:
   - Host: `mail.servicedesk-simulator.com`
   - Port: `443`
   - Encryption: `SSL/TLS`
   - Username: Full email address
4. Save configuration and allow up to 60 seconds for initial handshake and inbox sync.
