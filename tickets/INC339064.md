## 4. Root Cause & KB Notes

**Root Cause:** A buffer/OS fault on the Core Router (10.0.0.1) caused high latency and severe throughput throttling across all VLANs. A soft reset cleared the memory bottleneck and restored full routing performance.

**KB Article:** KB-1082

**Quick Resolution Checklist:**
1. Access the **Server Room** infrastructure management dashboard.
2. Select **Devices** and verify the status of edge and distribution hardware.
3. Locate the **Core Router (10.0.0.1)** and check for error states or abnormally high resource utilization.
4. Select the options menu (**...**) next to the Core Router and execute a reboot/restart.
5. Monitor node telemetry until the device status displays **ONLINE**.
6. Validate bandwidth metrics and confirm connectivity with the reporting user via **Team Chat** before closing the ticket.
