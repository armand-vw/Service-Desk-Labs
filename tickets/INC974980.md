## 4. Root Cause & KB Notes

**Root Cause:** Print Server (PRINT01) performance degradation and spooler responsiveness failure, showing critical resource utilization spikes (CPU 95%, Memory 90%). A soft reboot recycled system services, cleared print spooler resource locks, and restored floor-wide printing capability.

**KB Article:** KB-1089

**Quick Resolution Checklist:**
1. Open **Server Room → Servers** in the administrative dashboard to review node health metrics.
2. Locate the designated print server node (e.g., PRINT01) and inspect status, CPU, and RAM usage.
3. If the node is marked **DEGRADED** or showing locked spooler processes, select **Action → REBOOT** to trigger a controlled restart.
4. Verify the node returns to **ONLINE** status and utilization metrics stabilize.
5. Have an impacted end-user submit a sample print job to confirm spooler responsiveness.
6. Log remediation actions in ticket notes and close out the incident.
